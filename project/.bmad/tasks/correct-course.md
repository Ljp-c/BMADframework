# Task: Correct Course (纠偏/重构任务)

## 任务描述

当项目执行过程中发现偏差、技术债务积累或需要优化改进时，执行纠偏或重构任务，确保项目回到正确轨道或提升代码质量。

## 角色执行者

**任何角色** (根据问题类型确定主导角色)

## 触发条件

### 项目偏差
- 需求理解偏差
- 进度严重滞后
- 质量问题频发
- 技术方案不可行

### 技术债务
- 代码质量下降
- 架构设计问题
- 性能问题
- 安全隐患

### 优化改进
- 用户反馈问题
- 运维问题
- 可扩展性不足
- 可维护性差

## 执行步骤

### Step 1: 问题识别

- [ ] 识别问题现象
- [ ] 分析问题根因
- [ ] 评估影响范围
- [ ] 确定优先级

### Step 2: 方案制定

- [ ] 制定解决方案
- [ ] 评估方案可行性
- [ ] 评估资源需求
- [ ] 获得团队认可

### Step 3: 计划制定

- [ ] 制定详细计划
- [ ] 分解任务
- [ ] 估算工作量
- [ ] 确定时间表

### Step 4: 执行实施

- [ ] 按计划执行
- [ ] 跟踪进度
- [ ] 处理问题
- [ ] 记录变更

### Step 5: 验证确认

- [ ] 验证问题已解决
- [ ] 回归测试
- [ ] 获取确认
- [ ] 更新文档

### Step 6: 总结复盘

- [ ] 总结经验教训
- [ ] 更新最佳实践
- [ ] 分享团队知识
- [ ] 预防类似问题
