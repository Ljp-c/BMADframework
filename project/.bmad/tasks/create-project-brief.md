# Task: Create Project Brief (创建项目简报) - 智能体任务流程

## 任务描述

> **Analyst**: 我是本任务的执行者，负责创建项目简报文档，清晰定义项目背景、目标、范围、约束条件和成功标准，为后续产品开发奠定基础。

---

## 对话场景：任务执行过程

### 场景1：任务启动

**ProjectManager**: 新项目启动，请创建项目简报。

**Analyst**: 收到任务。让我开始信息收集。

### 场景2：信息收集

**Analyst**: Step 1: 收集信息

**User_Representative**: 我想做一个潮玩收藏管理工具。

**Analyst**: 请告诉我更多细节：
1. 目标用户是谁？
2. 解决什么问题？
3. 期望什么功能？

**User_Representative**: 
- 用户：潮玩收藏爱好者，主要是年轻女性
- 问题：不知道收藏值多少钱，记录混乱
- 功能：收藏管理、估价、报告生成

**Analyst**: 我来收集市场数据：

**市场调研结果**:
- 市场规模：1100亿元
- 年增长：20%+
- Pop Mart会员：5900万+
- Labubu销量：1亿+

### 场景3：问题陈述

**Analyst**: Step 2: 定义问题陈述

**问题陈述**：
潮玩收藏入门者缺乏快速、便捷的库存管理和估价工具，导致无法有效了解收藏品的价值，影响交易决策和收藏体验。

**当前问题**:
- 库存管理手动记账，数据容易丢失
- 估价依赖非专业渠道，准确性无保证
- 无法快速生成收藏报告

### 场景4：项目目标

**Analyst**: Step 3: 确定项目目标

**主要目标**:

| 目标 | 衡量标准 |
|------|----------|
| MVP验证 | 1-2周内注册用户>500 |
| 解决估价痛点 | 报告生成<5秒，满意度>4.5/5 |
| 建立用户基础 | 首月新增用户1000+ |
| 验证商业模式 | 付费转化率>1% |

**成功标准**:

| 标准 | 衡量方式 | 目标值 |
|------|----------|--------|
| 注册用户数 | GA统计 | >500 |
| 付费转化率 | 订阅数/注册数 | >1% |
| 系统性能 | 页面加载时间 | <2秒 |
| 用户留存率 | 7天活跃用户 | >30% |

### 场景5：项目范围

**Analyst**: Step 4: 定义项目范围

**范围内**:
- 收藏输入与管理
- AI估价报告生成
- 用户认证与订阅管理
- 基础可视化报告
- PDF/网页格式报告导出

**范围外**:
- 拍照识别功能
- 发售提醒/推送通知
- IP社区讨论功能
- 直接使用IP图像

### 场景6：约束与假设

**Analyst**: Step 5: 识别约束和假设

**时间约束**:
- 2026年2月25日启动
- 2026年3月21日上线
- 总周期3周

**预算约束**:
- 人力成本：0元（AI辅助开发）
- 基础设施：0元（Vercel免费层）
- 第三方服务：<150元/月

**技术约束**:
- 移动端优先
- 不能使用IP图像
- 数据加密存储

**关键假设**:
- 用户愿意为准确估价付费
- DeepSeek API稳定性符合预期
- 小红书/抖音获客有效

### 场景7：风险识别

**Analyst**: Step 6: 识别风险

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| IP版权风险 | 中 | 高 | 使用文本描述 |
| 支付集成失败 | 低 | 中 | 提前测试 |
| AI成本超预算 | 中 | 中 | 设置额度上限 |
| 用户体验不达预期 | 中 | 高 | MVP快速迭代 |

### 场景8：编写简报

**Analyst**: Step 6: 编写项目简报

**输出物**:
- [x] docs/project-brief.md - 项目简报文档

**ProjectManager**: 项目简报通过评审。

**Analyst**: 任务完成。下一步传递给PM创建PRD。
