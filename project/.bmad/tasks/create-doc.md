# Task: Create Document (创建通用文档)

## 任务描述

创建项目所需的各种文档，确保文档结构清晰、内容完整、易于维护，为团队提供有效的知识传递和参考。

## 角色执行者

**任何角色** (根据文档类型确定)

## 输入

- 文档需求描述
- 相关参考资料
- 项目上下文信息

## 输出

- 格式规范的文档文件

## 执行步骤

### Step 1: 确定文档类型

- [ ] 识别文档目的
- [ ] 确定目标读者
- [ ] 选择文档模板
- [ ] 确定存放位置

### Step 2: 收集信息

- [ ] 收集相关资料
- [ ] 访谈相关人员
- [ ] 整理现有信息
- [ ] 识别信息缺口

### Step 3: 编写文档

- [ ] 按模板结构编写
- [ ] 确保内容准确
- [ ] 使用清晰语言
- [ ] 添加必要图表

### Step 4: 审核完善

- [ ] 自我审核
- [ ] 同行评审
- [ ] 收集反馈
- [ ] 修改完善

### Step 5: 发布维护

- [ ] 发布文档
- [ ] 通知相关人员
- [ ] 建立维护计划
- [ ] 记录版本历史

## 质量检查清单

- [ ] 文档结构完整
- [ ] 内容准确无误
- [ ] 语言清晰易懂
- [ ] 格式规范统一
- [ ] 图表清晰有效
- [ ] 版本信息完整
- [ ] 已通过审核

## 交付验收标准

1. 文档符合模板规范
2. 内容完整准确
3. 已通过审核
4. 已发布到正确位置
5. 已通知相关人员
