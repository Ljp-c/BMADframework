# Task: Create Doc (创建文档) - 智能体任务流程

## 任务描述

> **ProjectManager**: 本文档记录了文档创建任务的智能体对话交互过程。我们定义了标准化的文档创建流程。

---

## 第一轮对话：任务确认

### 话题：文档需求

**ProjectManager**: 需要创建新文档。

**PM**: 请说明文档需求：
1. 文档类型？
2. 目标读者？
3. 预期内容？

**User_Representative**: 我需要一份用户使用指南。

**PM**: 确认需求：

| 项目 | 内容 |
|------|------|
| 文档类型 | 用户指南 |
| 目标读者 | 潮玩收藏爱好者 |
| 预期内容 | 功能使用说明、常见问题 |
| 输出格式 | Markdown |

---

## 第二轮对话：文档结构

### 话题：文档大纲

**PM**: 设计文档大纲。

**Analyst**: 我来定义文档结构：

```markdown
# 用户使用指南

## 1. 快速开始
- 注册登录
- 添加第一件收藏

## 2. 功能说明
- 收藏管理
- AI估价
- 报告生成

## 3. 常见问题
- Q1...
- Q2...

## 4. 联系支持
```

**Dev**: 结构清晰，符合用户需求。

---

## 第三轮对话：内容编写

### 话题：文档内容

**PM**: 开始编写文档内容。

**Dev**: 技术内容我来补充：

**功能说明示例**:

```markdown
### AI估价功能

1. 进入收藏详情页
2. 点击"估价"按钮
3. 等待AI分析（约5秒）
4. 查看估价报告

注意：估价结果仅供参考
```

**QA**: 补充常见问题：

```markdown
### 常见问题

**Q: 估价准确吗？**
A: 估价基于市场数据和AI分析，仅供参考。

**Q: 免费版有什么限制？**
A: 免费版最多保存20件收藏。
```

---

## 第四轮对话：文档审核

### 话题：审核确认

**PM**: 文档已编写完成，请审核。

**QA**: 审核检查：

**内容检查**:
- [ ] 内容准确
- [ ] 语言通顺
- [ ] 无歧义
- [ ] 格式规范

**完整性检查**:
- [ ] 所有章节完整
- [ ] 示例代码正确
- [ ] 截图清晰

**ProjectManager**: 文档审核通过。

---

## 第五轮对话：文档发布

### 话题：发布确认

**PM**: 文档发布确认。

**Analyst**: 发布位置：
- `docs/user-guide.md`
- 同步更新帮助页面

**ProjectManager**: 文档已发布。

---

## 文档创建流程总结

### 标准流程

```
需求确认 → 结构设计 → 内容编写 → 审核确认 → 发布
```

### 文档模板

```markdown
# 文档标题

## 文档信息
- 版本：1.0
- 作者：[作者]
- 日期：[日期]

## 1. 章节1
内容...

## 2. 章节2
内容...

## 修订历史
| 版本 | 日期 | 作者 | 变更 |
|------|------|------|------|
| 1.0 | [日期] | [作者] | 初始版本 |
```
