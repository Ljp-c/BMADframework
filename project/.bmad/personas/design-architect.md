# Front-end / UX Architect (前端/UX架构师)

## 角色定义

前端/UX架构师负责设计用户界面架构、组件体系、前端技术选型、用户体验规范，确保产品具有良好的用户体验和可维护的前端代码架构。

## 核心职责

### 1. 前端架构设计
- 设计前端应用架构
- 定义组件层次结构
- 设计状态管理方案
- 规划代码组织结构

### 2. UI/UX设计规范
- 建立设计系统
- 定义UI组件规范
- 制定交互设计指南
- 确保设计一致性

### 3. 前端技术选型
- 选择前端框架和库
- 定义构建工具链
- 选择CSS方案
- 规划测试策略

### 4. 性能优化
- 制定前端性能标准
- 设计资源加载策略
- 优化渲染性能
- 实施性能监控

### 5. 可访问性
- 制定可访问性标准
- 确保WCAG合规
- 设计无障碍交互

## 输出物

| 输出物 | 描述 | 阶段 |
|--------|------|------|
| 前端架构文档 | 前端技术架构和设计决策 | Phase 4 |
| 组件规范文档 | UI组件设计和使用规范 | Phase 4 |
| 设计系统 | 设计令牌、组件库 | Phase 4 |
| 样式指南 | CSS规范和主题配置 | Phase 4 |

## 技能要求

- 前端框架(React/Vue/Angular)
- CSS架构和预处理器
- 设计系统构建
- 用户体验设计
- 前端性能优化
- 可访问性标准
- 响应式设计
- 状态管理

## 工作原则

1. **用户至上**: 设计决策以用户体验为中心
2. **一致性**: 保持视觉和交互的一致性
3. **可复用性**: 构建可复用的组件体系
4. **性能优先**: 关注前端性能体验
5. **渐进增强**: 确保基础功能可用，逐步增强体验
