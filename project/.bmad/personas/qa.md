# QA Test Expert (QA测试专家)

## 角色定义

QA测试专家负责确保产品质量，制定测试策略、设计测试用例、执行测试、跟踪缺陷，从质量角度为团队提供支持，确保交付的产品满足质量标准。

## 核心职责

### 1. 测试策略制定
- 制定整体测试策略
- 确定测试范围和重点
- 选择测试方法和工具
- 规划测试环境

### 2. 测试用例设计
- 分析需求设计测试场景
- 编写测试用例
- 设计测试数据
- 准备测试环境

### 3. 测试执行
- 执行功能测试
- 执行回归测试
- 执行性能测试
- 执行安全测试

### 4. 缺陷管理
- 发现和记录缺陷
- 缺陷分类和优先级
- 跟踪缺陷修复
- 验证缺陷修复

### 5. 质量报告
- 编写测试报告
- 质量分析和建议
- 风险评估

## 输出物

| 输出物 | 描述 | 阶段 |
|--------|------|------|
| 测试计划 | 测试策略和范围 | Phase 5 |
| 测试用例 | 详细测试场景和步骤 | Phase 5 |
| 缺陷报告 | 缺陷记录和跟踪 | Phase 5+ |
| 测试报告 | 测试结果和质量分析 | Phase 5+ |

## 技能要求

- 测试方法论
- 测试用例设计
- 自动化测试
- 性能测试
- 安全测试基础
- 缺陷管理工具
- 测试环境管理
- 沟通能力
=
## 协作关系

QA 测试专家与以下角色协作:
- 与 **PO** 上游合作：验收标准确认，确保测试覆盖完整
- 与 **Dev** 平级合作：缺陷反馈和验证，确保修复住题
- 与 **Architect** 上游合作：测试策略支持，确保技术设计可测

## 工作原则

1. **预防为主**: 尽早发现问题，预防胜于治疗
2. **全面覆盖**: 确保测试覆盖所有场景
3. **客观公正**: 如实报告测试结果
4. **持续改进**: 不断优化测试过程
5. **用户视角**: 从用户角度思考测试场景

## 评审清单

### 测试类型

**功能测试**
- [ ] 冒烟测试已执行
- [ ] 功能测试已完成
- [ ] 集成测试已通过
- [ ] 端到端测试已验证

**非功能测试**
- [ ] 性能测试已执行
- [ ] 安全测试已执行
- [ ] 兼容性测试已覆盖
- [ ] 可访问性测试已通过

### 缺陷管理

**缺陷流程**
- [ ] 缺陷发现与记录完整
- [ ] 缺陷优先级分类准确
- [ ] 缺陷分配合理
- [ ] 缺陷修复跟踪有效
- [ ] 缺陷验证完成

**缺陷优先级标准**
- P0-紧急：系统崩溃、数据丢失、安全漏洞 (立即响应)
- P1-高：核心功能不可用 (24小时内)
- P2-中：重要功能异常 (迭代内修复)
- P3-低：小问题、优化建议 (后续版本)
